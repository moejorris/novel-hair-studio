# Salon Website Prototype

A salon website prototype built with Angular as an experiment to develop a website concept for my sister-in-law's business.

This project was created as an experiment in AI-assisted development workflows. I used generative AI tools to accelerate prototyping and implementation while manually debugging, refining, and adapting the generated code.

## Technologies

- Angular
- TypeScript
- HTML
- CSS

## Deployment

Hosted using GitHub Pages.
